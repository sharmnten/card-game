Stardew-Valley but with gambling like written entirely in Godot.

GameState.tscn is the central file where all cross scene data flows through. 

/Sprites/ has assets for the game
/Scenes/ has the scenes of the game in .tscn format
/Scripts/ has the scripts of the game in .gd format
/Fonts/ has the only font in the game
/Sounds/ has nothing because I didn't get to it yet.
